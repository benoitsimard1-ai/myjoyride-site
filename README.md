# myjoyride.net

Le petit site de My Joy Ride, hébergé gratuitement par GitHub Pages.

- `index.html` : la page d'accueil (liens pour essayer l'app, pages légales).
- `404.html` : la page « Rejoins la Joy Ride » pour les liens
  `https://myjoyride.net/joinCode/NUMERO`, quand l'app n'est pas installée.
- `.well-known/apple-app-site-association` : la preuve pour Apple que les liens
  de myjoyride.net peuvent ouvrir l'app iPhone `com.myjoyride.app`.
- `.well-known/assetlinks.json` : la même preuve pour Android.
- `CNAME` : le nom de domaine du site.
- `.nojekyll` : pour que GitHub publie aussi le dossier `.well-known`.

Aucun secret ici : ce dépôt est public.
